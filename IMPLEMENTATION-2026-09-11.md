# Förbättringar 11 september 2026

## Genomfört i granskningsgren
- Förenklad offert: företag valfritt i UI och API, tjänsteval först, samtliga sju tjänster, hjälp att välja, tekniska format infällbara, förvald tjänst från tjänstesidor.
- API bekräftar bara mottagning efter lyckad e-postleverans till leverantör eller accepterad webhook. Indata valideras och HTML kodas; personuppgifter skrivs inte längre till applikationsloggen. Detta bekräftar inte leverans till en faktisk inkorg.
- GA4 generate_lead efter API-framgång; ingen ny mätidentitet eller nya personuppgifter i analys.
- Mörkare orange för läsbar knapptext, tydligare hero-text, borttagna låtsaskoordinater.
- Omskrivna ingresser och metadata för tre prioriterade tjänster, tydligare startsida.
- Beslutsstöd, begränsningar och offertfrågor på samtliga sju tjänster.
- Preciserade påståenden om modellskattningar, tidiga barkborreangrepp, försäkringsunderlag, systemimport, LiDAR och multispektrala sensorer. Länkar till DJI och Skogsstyrelsen.
- Struktur för en anonymiserad referens per tjänst. Inga obekräftade referenser visas.
- Ägarrelationer och beslutet att inte namnge personer lämnas orörda.

## Återstår / kräver underlag
- Verkliga referenser: för varje tjänst behövs kundbehov, faktiskt genomförande, faktisk leverans och eventuella begränsningar. Tidigare case E1–E3 är EJ VERIFIERADE enligt CONTENT-VERIFICATION.md. Befintliga egna bilder bekräftar inte sju olika uppdrag.
- Faktiska prisexempel, verifierade importtester och kvalitetsmått saknas.
- Search Console/GA4/CRM: mätidentitet och mottagning behöver kontrolleras i drift; kvalificerade leads kräver affärsuppföljning utanför webbplatsen.
- Fullständig mobil/desktop-granskning, prestandamätning och extern mottagning enligt QA-CHECKLIST.md återstår före produktionspublicering.
- Regionala kundcase kan inte skrivas utan faktisk lokal erfarenhet. Inga nya likartade ortssidor skapade.
